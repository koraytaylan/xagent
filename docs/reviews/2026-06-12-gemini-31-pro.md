# Review of XAgent Learning Mechanisms

## Overall Assessment
The definition of intelligence, self-awareness, and "survival instinct" in the agent architecture is mathematically sound. The homeostasis phase in the brain accurately maps the rate of change of the agent's energy and integrity (gradients) into an exponentially scaling `urgency` value. This genuinely mirrors biological pain/survival instinct — driving agents to seek relief and amplifying learning signals exactly as needed.

However, the reason agents fail to associate cues like `danger=bad` or `food=good` despite possessing this internal survival drive boils down to **two massive mathematical bugs** in the neural update rules (`brain_passes.wgsl`). The cognitive machinery is unintentionally destroying its own representations exactly when learning is supposed to happen.

---

## Bug 1: The Encoder Temporal Mismatch (Amnesia Upon Eating)

### Finding
The agents use a REINFORCE-style delayed credit assignment. It takes ~30 ticks for an agent to approach and consume food. When the positive gradient eventually registers, the action selector appropriately pairs the positive credit with the *past* encoded state and the *past* random motor exploration (from the history buffer). This part is correct.

However, when the brain passes that credit backward to train the **Visual Encoder** (`O_ENC_WEIGHTS`), it multiplies the past `action_credit` by the **current** visual features (`s_features`).
* Because the food was just consumed, the agent is now likely staring at a blank wall or empty space.
* The update rule essentially says: "This positive reward we got from actions taken 30 ticks ago should be strongly associated with the blank wall you are looking at right now."
* This effectively forces the encoder to continually destroy its spatial representation of food every time the agent actually catches it. The agent is blind to causal spatial features because it keeps overwriting them with delayed sensory garbage.

### Proposed Fix
Instead of trying to use delayed REINFORCE credit to backpropagate through the encoder (which requires storing massive history buffers of raw 201-dim vision), the encoder should utilize an unsupervised Hebbian learning rule (specifically, Oja's Rule for Principal Component Analysis). 
This allows the encoder to self-organize instantly, preserving the maximum variance of the visual field without suffering from temporal credit delays.

**Proposed Changes to `brain_passes.wgsl`:**
```wgsl
    // ── 7b. Encoder credit: threads 0..31 ──────────────────────────────
    if (tid < ENCODED_DIMENSION) {
        // Replace broken delayed-reward credit with Oja's rule for PCA
        // This makes the encoder self-organize to preserve maximum variance
        // of the sensory input without suffering from temporal mismatch.
        let y = s_encoded[tid];
        let pca_lr = learning_rate * 0.05; // slower learning rate for encoder
        for (var j: u32 = 0u; j < FEATURE_COUNT; j = j + 1u) {
            let x = s_features[j];
            let w_idx = O_ENC_WEIGHTS + j * ENCODED_DIMENSION + tid;
            var w = brain_state[brain_base + w_idx];
            // Oja's rule: dw = alpha * y * (x - y * w)
            w = w + pca_lr * y * (x - y * w);
            w = clamp(w, -2.0, 2.0);
            brain_state[brain_base + w_idx] = w;
        }
    }
```

## Bug 2: The Predictor Autoencoder Bug (No Foresight)

### Finding
The predictor is meant to be a forward model, predicting the *future* state based on the *past* state.
In `Pass 6`, the code correctly makes a prediction of the future state based on the current state.
In `Pass 7` (the learning phase), the code calculates the prediction error as `predicted_dimension - s_habituated[tid]` (which is `newly_made_prediction_for_the_future - current_state`), and then trains the weights using `current_state` as the input.

By trying to minimize the difference between a newly generated prediction and the current state using the current state as input, the network is literally training itself to output the current state given the current state. It behaves as an identity autoencoder (`W * x = x`). It has zero predictive foresight.

### Proposed Fix
To be a true forward predictor, the network must minimize the error between the *previous prediction* and the *current state*, and backpropagate that error through the *previous input*. 

To accomplish this without expanding memory buffers, we simply need to delay the overwrite of `O_PREV_ENCODED` until the very end of `Pass 7`. This ensures that the predictor learning block has access to the previous tick's encoded state.

**Proposed Changes to `brain_passes.wgsl`:**

1. Change predictor to operate on `s_encoded` instead of `s_habituated` (to predict unattenuated state transitions).
2. Move the overwrite of `O_PREV_ENCODED` from `Pass 3` to the bottom of `Pass 7`.
3. Fix the prediction error calculation to map previous predictions to the current state.

```wgsl
    // ── 7a. Predictor learning: threads 0..PREDICTOR_DIMENSION ──────────
    if (tid < PREDICTOR_DIMENSION) {
        let previous_prediction = brain_state[brain_base + O_PREV_PREDICTION + tid];
        let current_target = s_encoded[tid]; // Predictor targets s_encoded
        let error_dimension = previous_prediction - current_target;
        let tanh_deriv = 1.0 - previous_prediction * previous_prediction;
        for (var j: u32 = 0u; j < ENCODED_DIMENSION; j = j + 1u) {
            let prev_input = brain_state[brain_base + O_PREV_ENCODED + j]; // Train using past input
            let grad = clamp(error_dimension * tanh_deriv * prev_input, -1.0, 1.0);
            var w = brain_state[brain_base + O_PREDICTOR_WEIGHTS + tid * ENCODED_DIMENSION + j] - learning_rate * grad;
            w = clamp(w, -3.0, 3.0);
            brain_state[brain_base + O_PREDICTOR_WEIGHTS + tid * ENCODED_DIMENSION + j] = w;
        }
    }
```

```wgsl
    // Add to the very end of Pass 7

    }
```

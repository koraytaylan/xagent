# Review: Why a 24h / 1834-Generation Run Produced No Learning and No Evolution — A Spatially-Blind Reward

**Date:** 2026-06-14
**Reviewer:** Claude Opus 4.8
**Scope:** the full learning-and-evolution stack, cross-referenced against a real
~24h production run (`xagent.db`, 1834 generations): the reward/credit path in
`crates/xagent-brain/src/shaders/kernel/brain_passes.wgsl` (homeostatic
`raw_gradient`, TD(λ) actor-critic, eligibility traces, value head, policy
readout, klinotaxis, pattern-memory valence), the learning constants in
`common.wgsl`, the food-detect data in `kernel_tick.wgsl`, the vision geometry
in `phase_vision.wgsl`, the fitness/selection/momentum machinery in
`crates/xagent-sandbox/src/governor.rs`, the run/world config
(`crates/xagent-shared/src/config.rs`), and the documented baselines
(`docs/superpowers/specs/2026-06-10-learning-baseline.md`,
`docs/superpowers/specs/2026-04-21-credit-assignment-audit.md`,
`EVOLUTION_JOURNEY.md`).

**Question under review:** After a ~24h run, neither learning (within a lifetime)
nor evolution (across generations) works. Are we twisting the wrong knobs, or is
there a fundamental architectural error?

**Method:** Measured the run directly from `xagent.db`, then ran a six-lens code
investigation (credit-assignment, encoder/policy, reward signal,
fitness/selection, genome↔phenotype, world/experiment) with adversarial
verification of every claimed root cause. 26 findings survived verification;
they converge on one cause.

---

## TL;DR

It is a **fundamental architecture error**, and yes — every knob tuned so far is
*downstream* of it. The single root cause:

> **The learning reward is spatially blind. The agent is rewarded by how it
> *feels* (its own energy/integrity delta), never by its *relation to food*.**

`brain_passes.wgsl:170,188,190`: `raw_gradient = energy_delta·0.6 + integrity_delta·0.4`,
then `reward = raw_gradient·(1+urgency)`. A grep of the entire reward path
returns **zero** distance/bearing/approach terms — the only ones are in comments.
Food direction enters the brain solely as vision pixels in `s_encoded`, which
feeds the policy readout (`:521-522`) and the critic's value estimate — but
**never the reward that trains them**.

**The analogy.** You are training a dog to fetch, but the treat-dispenser is
wired to the dog's blood sugar instead of to the ball. Walking toward the ball
and walking away feel *identical* — the same slow hunger — until its mouth
touches it. No treat size, breed, or schedule teaches direction, because the
signal never depends on direction. That is the agent: during the entire approach
to *visible* food, reward is a near-constant metabolic drain, the same whether
steering toward food or away, until the one contact-eat tick (~once per 700 brain
ticks).

This is not a dozen bugs. It is **one blindness wearing a dozen costumes.** The
credit machinery, eligibility traces, critic, actor readout, klinotaxis, and
memory are each *individually sound* but all wired to a reward that cannot teach
steering. Fix any one costume and you get another flat 1834-generation run.

## The causal chain (root → "no learning" → "no evolution")

Each link is measured, not assumed.

1. **Reward carries no approach gradient.** During the ~4.5-brain-tick approach
   to seen food, reward is a near-constant negative (metabolic drain), *identical*
   for correct and incorrect steering. The only positive is the +0.20 energy jump
   on contact-eat. (`brain_passes.wgsl:170,188,190,423`)

2. **The actor's REINFORCE gradient has nothing bearing-correlated to latch
   onto.** The turn update is `Δw_turn[d] = 0.10·(1/128)·δ·turn_trace[d]`, with
   `turn_trace[d] = γλ·turn_trace[d] + noise_turn·s_encoded[d]`
   (`:709-712`). For "food-left → turn-left" to build,
   `E[δ·noise_turn·s_encoded[d]]` must be sign-correct per state — but `δ` is
   built from the spatially-blind reward, so it carries no information about which
   way the noise kicked relative to food. Under a mirrored-food probe the
   conditional component averages to **exactly zero**; only a state-*independent*
   bias survives. Empirically: alignment 0.498, flat across episodes. **The actor
   is structurally incapable of learning state-conditional steering from this
   signal.**

3. **The critic cannot rescue it via bootstrapping.** The intended escape hatch
   — critic learns `V(food-in-view) > V(no-food)` so `δ` goes positive the instant
   food appears — fails because (a) the critic's only teacher is the same blind
   reward, and (b) its effective rate is `CRITIC_LEARNING_RATE·TD_VECTOR_SCALE =
   0.01/128 ≈ 8e-5`, so `V` stays flat (measured ≈ −0.002). Flat `V` ⟹
   `γV(s′)−V(s) ≈ 0` ⟹ `δ ≈ raw sparse reward`. No early credit is synthesized.

4. **No steering ⟹ diffusive (not directed) foraging.** Alignment ≈ 0.5 turns a
   ballistic searcher's ~7.3 food/1k-ticks into the observed ~0.14 — a ~52×
   collapse — putting agents ~11× below the 1.5-food/1k break-even.

5. **Chronic starvation ⟹ 276 deaths/gen ⟹ the multiplicative survival gate
   crushes fitness.** `survival = 1/(1+0.5·deaths) ≈ 0.0072`; the composite
   becomes ~0.0014 with intra-generation spread (~0.00036) at or below the
   eval-noise floor (`governor.rs:54-68`, `:62,:67`).

6. **Evolution has no selectable signal ⟹ it random-walks.** With only 2 unique
   configs/gen (`unique_count = 5/2 = 2`) and a bare `gen_avg ≥ parent_fitness`
   accept rule, selection is a coin flip (0.76% success). The only above-noise,
   monotonically-rewarded lever is "spend less energy" — so momentum-amplified
   drift pushes the metabolic-cost proxies `processing_slots` 16→1 and
   `memory_capacity` 128→1, which do nothing for cognition.

One blindness at the reward source propagates deterministically all the way to
"evolution selects on noise and finds only the metabolic-cost proxy."

## Fundamental architecture errors vs wrong-knob mis-tunings

**FUNDAMENTAL (the design cannot work as built — a code/structural change is
required):**

- **F1 — Spatially-blind reward.** THE root. A learner cannot acquire
  vision-conditional approach from a reward containing no approach gradient.
  (`brain_passes.wgsl:170,188,190`)
- **F2 — REINFORCE conditional gradient vanishes in expectation.** The corollary
  of F1 on the actor side: even a perfect critic cannot make `noise×encoded×δ`
  build conditional steering under a symmetric food distribution. Fixed *by* F1
  (a dense, sign-correct `δ`), or by replacing REINFORCE with an advantage-weighted
  / supervised "turn toward the highest-value visible direction."
- **F3 — Klinotaxis driven by self-energy, not an external gradient.**
  `gradient_deviation = s_homeo[3]−s_homeo[4]` — both EMAs of the *same*
  interoceptive `raw_gradient` — so both relax equally during approach ⟹
  `klinotaxis_factor → 1.0` (inert). Real chemotaxis compares an *external*
  concentration across time. The reactive layer is wired to the wrong input; it
  fires only *after* eating/damage. (`brain_passes.wgsl:653-655`)
- **F4 — Policy learning constants are hardcoded; the "Active" genes are causally
  inert.** `CFG_LEARNING_RATE` feeds *only* the peripheral predictor (`:320`);
  `ACTION_WEIGHT_LEARNING_RATE`, `CRITIC_LEARNING_RATE`, `KLINOTAXIS_SENSITIVITY`,
  `TD_DISCOUNT/LAMBDA` are all `const` (`common.wgsl:277,294,298,301`). The two
  evolvable cognitive genes cannot move the policy's learning dynamics —
  evolution searches a subspace disconnected from behavior.
- **F5 — The experiment cannot reveal learning.** Below-noise signal × 2
  configs/gen × bare mean-comparison. Even a *working* learner's ~8% edge is
  statistically invisible at this resolution.
- **F6 — No within-lifetime instrumentation on the governor path.** The run
  records only end-of-life aggregates; the q1→q4 foraging metric exists only in
  the headless side-tool (`headless.rs:380-383`), so the production run could not
  detect within-life learning even if it occurred.

**WRONG-KNOB / mis-tuning (a formula or parameter change fixes it):**

- Multiplicative survival gate compressing dynamic range into the 0.007 tail
  (`governor.rs:62,67`).
- `1/128` `TD_VECTOR_SCALE` crushing the *actor* LR to ~8e-4 (the 1/128 is a
  *critic*-stability argument; the actor should get its own larger scale).
- Sensory lag 100 / `vision_stride=10` — the lag sweep already proved lag=2 gives
  ~14× foraging; make stride heritable.
- Death-penalty dominance ~17× over the food reward.
- `population_size=5` / `eval_repeats=2` / `num_islands=3` — too small to select.
- Spawn-bar ratchet + momentum-learned-from-noise (add `child−parent > k·stderr`).
- Mutating metabolic proxies (`processing_slots`, `memory_capacity`) as if they
  were cognitive knobs.

## Secondary issues that compound the root (worth confirming when F1 lands)

- **Memory may be a *second* spatially-blind learner that teaches avoidance.**
  Recall blends stored motor by `sim·valence`, and valence is written from the
  same `raw_gradient` (`:787,:813`; blend `:536-539`). A food-in-view state gets
  *negative* valence during approach, so recall injects a negative-valence blend
  that, per the code's own comment (`:527`), "negates approach → escape."
- **Food teleports to a random new location on every successful eat**, destroying
  the approach-then-reward association the learner needs.
- **Within a kernel batch the encoded state is frozen for 10 brain ticks while
  the agent moves ~100 physics ticks**, so eligibility traces credit a state that
  is not the one in which the steering action was taken.
- **Vision row geometry blinds the agent to ground food beyond ~5 units.**
  `phase_vision.wgsl:31-37`: 6 vertical rays over a 90° FOV, half pointing up at
  sky; the shallowest down-ray (~11°) hits ground at ~5 units, so food at
  navigational range falls between ray rows and is invisible. Even a perfect
  steerer has a ~4-tick reaction window in free-roam.
- **`urgency` amplification can invert late-approach credit:** as energy drops
  near death, urgency rises and amplifies the *negative* drain reward more than
  the +0.20 eat — the sign asymmetry worsens exactly when the agent is hungriest.

## What is *not* the problem

- **The world is not too hard.** A perfect forager hits ~4.8× the survival
  break-even in this world; the entire deficit is the missing vision→approach
  conversion.
- **The information path is fine.** 16/16 agents see the probe food; vision
  delivers food pixels into `s_encoded`. The encoder reportedly preserves
  food-left/right separability. The brain *has* the bearing — the *reward* never
  references it.
- **The credit machinery is individually sound.** Eligibility traces, the
  actor-critic structure, the policy readout, and TD(λ) are all correctly built.
  They are simply fed a reward that cannot teach steering.
- **The definition of intelligence is fine.** "Let them discover food=good,
  danger=bad" is the right framing — but discovery requires a reward that varies
  with the thing being discovered.

## Highest-leverage interventions (ranked)

1. **Add potential-based approach shaping to the reward — THE unlock (~30 lines
   of WGSL).** `Φ(s) = −k·distance_to_nearest_visible_food`; add
   `F = γΦ(s′) − Φ(s)` into `raw_gradient` before the EMAs
   (`brain_passes.wgsl:170`). The data already exists in the food-detect pass
   (`kernel_tick.wgsl:229-235`). Potential-based shaping is provably
   policy-invariant (it cannot corrupt the eat objective), and it simultaneously
   gives the actor a sign-correct conditional `δ` (fixes F1, F2), feeds the
   critic, and feeds klinotaxis and memory valence if rewired. **Nothing else
   matters until this lands.**
2. **Replace the multiplicative survival gate** with `food_per_1k_alive_ticks` as
   the primary objective (`governor.rs:54-68`) — restores dynamic range where the
   agents actually live, so the new foraging variance is visible to selection.
3. **Raise experiment resolution:** decouple `population_size` from `eval_repeats`
   (≈8–16 unique configs × 4–6 repeats with *independent* world seeds),
   `num_islands→1`, add a significance guard `child−parent > k·pooled_stderr`.
   Verify the per-repeat seed actually varies.
4. **Promote the policy/critic learning constants into `BrainConfig`**
   (`common.wgsl:277,294,298,301` + buffers + config) so evolution can tune the
   dynamics that produce steering, and give the *actor* a separate, larger vector
   scale than the critic's 1/128.
5. **Reduce sensory lag** (make stride heritable; lag=2 → ~14× foraging) **and fix
   the vision row geometry** (odd height / a horizon-grazing row) so food is
   visible beyond touch range. Both are prerequisites for *fairly evaluating* #1 —
   a perfect approach reward is wasted if the agent can't see the food or acts on
   100-tick-stale state.

## How to prove or kill this diagnosis fast

Implement #1 and run the existing alignment probe
(`learning_probe_baseline_turn_alignment_is_chance`,
`learning_probe_free_run_foraging_baseline`): the diagnosis predicts
turn/bearing alignment moves decisively above the 0.62 band edge and free-run
foraging rises within a fixed-seed 20-generation headless run. If alignment stays
at chance after potential shaping lands, the encoder/representation is the next
suspect; if it moves, the rest of the chain is a tuning exercise.

**Blunt bottom line:** fix the reward, and the credit machinery, traces, critic,
actor readout, klinotaxis, and memory become a tuning problem. Tune everything
*except* the reward, and you will get another flat 1834-generation run.

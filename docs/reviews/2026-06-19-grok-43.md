## Executive Summary

**Overall health:** The project is in excellent mechanical shape for its current scope. All quality gates are green, 150+ integration + unit tests (many GPU-exercising with self-skip), strong fused/split parity discipline, exhaustive const mirroring tests, and no TODO/FIXME anywhere in `crates/`. The 0009/0010/0011 sequence delivered exactly what the four 2026-06-18 reviews diagnosed and requested: effort-rebased fitness + speed-invariant graded hazard + danger percept + symmetric potential shaping + intent metric, all flag-gated with byte-identical legacy defaults, re-derived production-scale calibration, hardened paired A/B gate, stale-telemetry/sign fixes, and a source scrub that ratcheted planning-debt counts downward across 13 files/44 lines without behavioral change.

**Forward-looking maintenance burden and development sustainability:** **High but bounded and predictable.** 
- The process (implement-plan + worktree DAG + mandatory reviewer loop + machine CONTRIBUTING guard + REVIEW-CHECKLIST pass) is heavyweight by design: small targeted edit touching governor or a shader typically costs 1-3 developer-days + independent review cycles. A new brain pass or credit-assignment change is 2-6 weeks including probes, parity, and gate data.
- Architectural concentration risk is real: `governor.rs` (4,990 LOC, one 233-line `advance()` that owns scoring + island policy + breeding + persistence), `gpu_kernel.rs` (3,534 LOC), `ui.rs` (2,159 LOC), `headless.rs` (1,540 LOC), `integration.rs` (large test surface), and the single fused 854-line kernel_tick.wgsl (plus mirrors in phase_*). CONTRIBUTING.md itself flags `governor.rs` as priority #1 for incremental cleanup.
- Invariant surface is wide and unforgiving (GPU buffer layout canonical sources, 16-byte uniform alignment, barrier uniformity via s_alive broadcast, numeric `max(..., EPSILON)` on every divisor in Rust+WGSL, no lossy `as`, fused/split exact symmetry on every accumulator, async readback authority, death/respawn resets). A single missed mirror or unguarded div is a validation error or silent corruption at runtime.
- Offsetting positives: ratchet guard prevents regression on debt, tests are falsifiable and exercise the risky paths (including post-respawn survival of accumulators), DB migrations are idempotent ALTERs, and recent 0009/10/11 work demonstrably followed the hygiene rules (named consts with "why" docs for all new fitness targets, no new magic numbers, no new plan refs beyond the ratcheted baseline).
- Estimate for a competent team familiar with the rules: sustaining velocity of ~1 plan/quarter (as seen 0007-0011) is realistic. Onboarding to productive contribution on the kernel and governor is 2-4 weeks.

**Drift from original goals (README vision + early superpowers):** **Moderate, pragmatic, and mostly on the selection side rather than the agent brain.** 

The core hypothesis ("No hardcoded goals. No reward functions. A numerically flattened brain interface." + predictive processing + homeostatic stability as the *only* evaluative signal inside the agent, with fear/curiosity/habit emerging from capacity constraints) remains intact in the 7-stage brain pipeline (`feature_extract → encode → habituate_homeo → recall → predict_and_act → learn_and_store` with TD(λ) actor-critic + eligibility traces, no history ring). The numeric flattening caveat (hand-crafted positional layout + top-4 touch priors + surface_tag scalar) was already acknowledged in the README.

What has shifted:
- Evolutionary selection (the meta-objective across generations) is now heavily shaped: effort-rebased (food-per-energy, cells-per-distance-rate), super-linear drag, graded path-length hazard (never lethal, preserves data), dedicated danger percept (flag-gated) + potential-based avoidance shaping, and an explicit "intent" metric (sensed-then-turned fraction) for observability and selection. This directly responds to the "spatially-blind reward" root cause diagnosed in the 2026-06-14-claude-opus-48.md review and the speed-exploit findings in 0009 SCOPE.
- The agent brain still sees only homeostatic deltas + prediction error; the new shaping is added at the fitness + (flag-gated) habituate_homeo potential level. This is "scaffolding" that increases over the original "one small reactive substrate (klinotaxis)" + sensory packer bias.
- Agent-level within-life reproduction (`spawn_child`, `REPRODUCTION_THRESHOLD`, `has_reproduced` in agent/mod.rs + evolution.rs) exists but is `#[allow(dead_code)]` and not wired into the main simulation path; generational replacement via Governor::breed_next_generation (elitism + momentum-biased mutation + crossover + islands) is fully active and the focus of recent plans. README still says "Reproduction: currently disabled to focus on individual learning rather than evolution" — this is now imprecise (generational evolution is the point of 0004/0007/0009/0010).
- Visual cortex (0008) ships complete and probe-proven (DoG + Gabor simple cells → complex cells with heritable genes) but remains default-off due to ~420× throughput regression; the 0005/0006 occupancy and tiling wins were real (+96% at N=10 in fused) but the knee and brain-pass dominance (≥93% of time) were not moved.
- Learning strength remains near the 2026-06-10 baseline in the critical probe (turn/bearing alignment still ~chance; foraging still mostly accidental contact). 0004 shaping was correctly rejected on negative evidence; 0007 grounded control signals and provenance but did not produce a decisive spatial learner.

In short: the platform is closer to a *high-fidelity evolutionary search harness for brain configs* (with improving selection signal) than the pure "observe genuinely emergent cognition from homeostatic pressure alone" demo of the original vision. This is a rational response to measured reality (weak learner + speed exploits crushing signal), not a betrayal, but it does increase the amount of hand-crafted prior in the fitness layer.

## Architecture & Process Soundness

The 3-crate split (shared interface, brain = sole owner of the fused GpuKernel, sandbox = world + orchestration + evolution + egui) is still respected. CPU never does per-tick work that scales with `ticks_to_run`; all simulation lives in WGSL; readback is non-blocking latest-wins snapshots on the main thread. Async readback authority is documented and respected for the new fitness fields (CPU accumulators in Agent + governor.evaluate write the authoritative values; GPU telemetry echoes are secondary).

The planning + review + guard process has demonstrably improved since the 04/ early-06 reports: 0009 was reviewed by four models the same day, 0010 was literally the task list from those reviews, 0011 paid the specific hygiene debt, and the ratchet now prevents re-introduction. This is one of the strongest process wins visible in the history.
